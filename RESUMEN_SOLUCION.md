## Cómo usar esta solución:

### Paso 1: Crear el repositorio en GitHub
Sigue la guía en `GUIA_REPOSITORIO_RESENAYA.md` para crear el repositorio "resenaya" en GitHub.

### Paso 2: Usar el script de configuración
```bash
# Después de clonar tu repositorio resenaya:
cd resenaya
python /ruta/al/script/setup_resenaya.py
```

### Paso 3: Configurar VS Code
El script copiará automáticamente las configuraciones de VS Code optimizadas para trabajar con GitHub Copilot.
