# Configuración de Ejemplo para VS Code

Este directorio contiene archivos de configuración de ejemplo para usar en tu proyecto "resenaya".

## Archivos incluidos:

- `vscode-settings.json`: Configuración recomendada para VS Code con Copilot
- `vscode-launch.json`: Configuración de debugging
- `gitignore-python`: Ejemplo de .gitignore para proyectos Python
- `requirements-example.txt`: Ejemplo de requirements.txt

## Cómo usar estos archivos:

1. Copia estos archivos a tu proyecto "resenaya"
2. Renombra los archivos según corresponda:
   - `vscode-settings.json` → `.vscode/settings.json`
   - `vscode-launch.json` → `.vscode/launch.json`
   - `gitignore-python` → `.gitignore`
   - `requirements-example.txt` → `requirements.txt`

## Personalización

Puedes modificar estos archivos según las necesidades específicas de tu proyecto.
